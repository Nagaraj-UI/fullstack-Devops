## 🐛 Troubleshooting Common Issues

### Issue: Database still shows "employee_db"
**Solution:**
1. Stop the backend (Ctrl + C)
2. Check `backend/.env` file shows: `MONGODB_URI=mongodb://localhost:27017/Devops`
3. Restart backend: `npm run dev`
4. Check startup logs for "Database: Devops"

### Issue: "Collection has no data" in MongoDB Compass
**Solution:**
1. Click the **Refresh** button in Compass
2. Ensure you're looking at the "Devops" database (not "employee_db")
3. Add at least one employee from the frontend first

### Issue: Frontend shows "🔴 Offline"
**Solution:**
1. Ensure backend is running
2. Test: `Invoke-RestMethod -Uri "http://localhost:5000/health"`
3. Check backend terminal for errors

### Issue: "Email already exists" error
**Solution:**
- This is correct behavior if email is duplicate
- Use a different email address
- Or delete the existing employee first
